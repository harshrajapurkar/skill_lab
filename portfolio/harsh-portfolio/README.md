# Harsh Rajapurkar — Responsive Portfolio

A four-page portfolio website built with HTML, CSS, and vanilla JavaScript.

## Pages
- `index.html` — Home / landing page
- `about.html` — About, learning journey, skills
- `projects.html` — Project cards with category filters
- `contact.html` — Contact information and validated email-draft form

## Run it
1. Extract the ZIP.
2. Open the `harsh-portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Before publishing, replace the placeholder email and social links, and update project descriptions to match your actual work.

No build step or external libraries required. The contact form does not send data to a server; it prepares an email using the visitor's email app after you replace the placeholder address.
