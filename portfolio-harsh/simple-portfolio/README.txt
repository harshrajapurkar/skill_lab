SIMPLE RESPONSIVE PORTFOLIO

Files:
- index.html: Home page
- about.html: About page
- projects.html: Projects page
- contact.html: Contact page
- css/style.css: All styling and responsive design
- js/script.js: Small JavaScript interactions

How to run:
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.

This version intentionally uses beginner-friendly HTML, CSS and JavaScript.
The contact form displays a confirmation message; it does not send data to a server.
Edit the text to suit your own details.
